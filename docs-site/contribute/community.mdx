Please do not report security problems in public issues. Follow the security policy instead.

## Good first contributions

A palette, a platform in `src/lib/platforms.ts`, or a docs fix. Adding a whole new look is a bigger job: see [Adding a look](/contribute/guide#adding-a-look).
