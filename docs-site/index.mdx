Posy is a link-in-bio page (a Linktree alternative) with six hand-made **looks**. A page is one JSON document, so you can edit it in the studio, hand it to an AI, or script it. It is open source and you can host it yourself.

## How it fits together

- **The studio** is the editor at posy.page. You paste a link and Posy picks the right tile.
- **The page file** is a small JSON file any chat can write. Load it at [`/new`](https://posy.page/new). See [the page file](/agents/format).
- **The MCP server** lets an AI app edit your page directly. Everything it does lands in your draft until you publish. See [MCP tools](/agents/tools).
- **The REST API and CLI** do the same from scripts. See the [API reference](/api-reference/introduction).
